# 🎮 Number Guessing Game Using Python

A simple and fun number guessing game built using Python 🐍

## 🚀 Features

- Random number generation
- Multiple difficulty modes
- Attempt counter
- High / Low hints
- Infinite guessing loop until correct answer
- Modular function-based structure

-----------------------------------------------------

## 🎯 Difficulty Modes

| Mode | Range |
|------|------|
| Easy | 1 - 10 |
| Medium | 1 - 100 |
| Hard | 1 - 500 |
| Very Hard | 1 - 1000 |

--------------------------------------------------------

## 🧠 Concepts Used

- Functions
- Loops
- Conditional Statements
- Random Module
- Match Case
- User Input
- Counters
- Return Values

## ▶️ How To Run

1. Clone the repository

```bash
git clone <your-repo-link>
```

2. Open project folder

```bash
cd <project-folder>
```

3. Run the Python file

```bash
python3 number_guessing_game.py
```
